## ✦ Working Tools

> Runs 100% in your browser — files never leave your device.

```
┌─────────────────────┬────────────────────────────────────────────────┐
│  🖼️  Image to PDF   │  Convert JPG, PNG, WebP images into a PDF      │
│  📄  PDF to JPG     │  Extract every page as high-quality JPEGs       │
│  📝  TXT to PDF     │  Convert plain text into clean formatted PDFs   │
│  📊  CSV to PDF     │  Turn spreadsheet data into a printable table   │
│  🌐  HTML to PDF    │  Render HTML files or snippets as PDFs          │
│  🔍  PDF OCR        │  Extract searchable text from scanned PDFs      │
│  📋  Flatten PDF    │  Merge form fields into a static, flat PDF      │
└─────────────────────┴────────────────────────────────────────────────┘

```

## 🔒 Privacy

```
  Core tools  ──────────────────────────►  100% in your browser, zero network calls
  AI tools    ──────────────────────────►  PDF sent to Gemini only, never stored
  Conversion  ──────────────────────────►  File sent to CloudConvert, deleted after download
```

No accounts. No tracking. No data stored.

## ⚙️ Stack

```
Frontend   │  React 19 · Vite 8 · TypeScript · Tailwind CSS v4
Routing    │  React Router v6
Backend    │  Supabase Edge Functions (Deno + Hono)
AI         │  Google Gemini 2.0 Flash Lite
Conversion │  CloudConvert API v2
Fonts      │  Sora · Inter · JetBrains Mono
```

## ▶ Getting Started

git clone https://github.com/vikkyjakhar/PaperTrail.git
cd PaperTrail
pnpm install
pnpm dev
# → http://localhost:8443
```
